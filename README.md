# ATELIER

Propuesta de proyecto CRUD para una plataforma de moda independiente.

## Cómo abrir el proyecto

1. Abrir esta carpeta desde Visual Studio Code.
2. Abrir `index.html` en un navegador (por ejemplo, Google Chrome).

## Publicación en GitHub

Crear un repositorio en GitHub y subir el contenido de esta carpeta. El archivo principal del sitio es `index.html`.
